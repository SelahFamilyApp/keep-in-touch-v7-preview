# Keep in Touch — Public V7 Test Preview

**Only static, previously public-facing demonstration assets are stored here.** The original V7 source repository `SelahFamilyApp/keep-in-touch-premium-website` remains **private**.

This repository has no employee dashboard, passwords, review page, research database, original product photos, or approved original design PNGs. These static website files are served by GitHub Pages as a public, non-transactional concept demonstration; verified prices, inventory, checkout and orders are disabled for genuine product families.

The public demo is for a small number of invited testers, but anyone with the URL can access it. Do not use as a production e-commerce service. Photo reuse is authorized for the demo only, not commercially licensed.
